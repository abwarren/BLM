# BLM — Core Project Identity

BLM (Betting Line Model) is a sports betting analytics and data-intelligence platform. It collects and preserves betting-market observations, builds historical datasets, analyses market behaviour, generates measurable predictions and evaluates those predictions against actual settled outcomes.

## Core principles
- Data integrity before model complexity.
- Verified evidence before assumptions.
- Historical evaluation against actual outcomes.
- Reproducible calculations and traceable inputs.
- Small, testable changes rather than unnecessary rewrites.

## Current top-level priority
Establish a reliable PokerBet collector that consistently retrieves, parses, validates and persists clean market data. Do not divert effort into unrelated features until this collection objective has been demonstrated and accepted.

## Important distinction
BLM analytics, predictions and alerts are not proof of profitable betting performance. Financial execution is a separate, safety-controlled subsystem.
